Document Intelligence

Send a PDF or a ZIP of page images and receive structured HTML with page-level metrics. Ideal for digitising forms, invoices and scanned records.

  • PDF & ZIP uploads up to 200MB
  • Configurable language & output format
  • Job-based processing with status polling

Text to Speech

Turn text into natural speech with selectable speakers, pace and sample rate. Audio is generated on demand and served back as downloadable WAV files.

  • Multiple Indian language voices

API reference

Three routes, plain JSON responses.

POST /api/document-intelligence/process

Process a PDF or ZIP document and return download links.

POST /api/text-to-speech/convert

Convert text into speech and receive downloadable WAV files.

GET /api/text-to-speech/download/:filename

Download a previously generated audio file.

Built with Express & SarvamAI. Runs locally on port 3000.
